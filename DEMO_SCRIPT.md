# Demo Video Script — FraudSentinel AI
### Total runtime: 3 minutes

---

**0:00 – 0:20 | Hook & Problem**
Screen: Title slide / dashboard landing page.
Narration: "Digital lending fraud is evolving faster than static rule engines can keep up — and most fraud AI today is a black box. FraudSentinel AI stops fraud in real time and explains every decision in plain English."

---

**0:20 – 0:45 | Architecture Overview**
Screen: Slide 4 (architecture diagram).
Narration: "Under the hood, every transaction runs through a hybrid engine: deterministic rule checks, an ML fraud score, pgvector similarity search against known attack patterns, and an AWS Bedrock explanation layer — all in under 200 milliseconds."

---

**0:45 – 1:30 | Live Dashboard Walkthrough**
Screen: Dashboard, click "Start stream."
Narration: "Here's the live dashboard. I'll start the transaction stream — each one is evaluated in real time and color-coded green for approve, yellow for flag, red for block." (Pause, let a few transactions render.)
"On the right, we're tracking decision latency live — staying well under our 200ms target."

---

**1:30 – 2:15 | XAI Explanation Modal**
Screen: Click a flagged (yellow) transaction to open the XAI modal.
Narration: "Clicking into a flagged transaction opens the explanation generated by AWS Bedrock. It shows the confidence score, the ML fraud score, which rules triggered, which historical fraud patterns it matched, and a feature-importance breakdown — all in plain English an analyst can act on immediately."

---

**2:15 – 2:45 | Analyst Feedback Loop**
Screen: Click "Confirm Fraud" in the modal.
Narration: "When an analyst confirms fraud, that transaction's behavioral signature is immediately promoted into our pattern library — so the very next similar attempt is caught faster. The system gets sharper with every review, without needing a full retrain."

---

**2:45 – 3:00 | Close**
Screen: Return to dashboard metrics view.
Narration: "FraudSentinel AI: real-time detection, explainable decisions, and a feedback loop that keeps improving — built for Synchrony's digital lending ecosystem. Thank you."

---

### Recording Checklist
1. Seed the demo database with a handful of confirmed `fraud_patterns` so at least one live transaction produces a strong pattern match.
2. Confirm `BEDROCK_MODEL_ID` and AWS credentials are configured so the XAI narrative is live, not the fallback text.
3. Pre-warm the HNSW index (run one query before recording) so the first live similarity search isn't artificially slow.
4. Keep the browser console closed during recording; verify no error toasts appear during the stream.
